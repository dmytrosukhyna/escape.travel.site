Generated by `tools/appstore.js`. Re-run it after any change to the site's
components and the screenshots follow, because they are built from the same
markup and stylesheet the site uses — there is no second copy of the design to
drift out of date.

```
node tools/appstore.js
```

## Read this before uploading

**These are mock-ups of the product's screens, not captures from a running
build.** They are drawn from the same components the marketing site uses. Apple
requires store screenshots to show the app as it actually is (App Review
Guideline 2.3.3), and a listing whose screenshots do not match the shipped app
is a rejection and, repeated, a developer-account problem.

So before these go up, one of two things has to happen:

- re-shoot all five frames from the real build on a device or the simulator,
  keeping these as the layout and caption template; or
- check them screen by screen against the real app and correct anything that
  differs — the row labels, the prices shown, the tab bar, the status bar.

Everything else in the frames — the caption, the gradient, the garland, the
snow — is marketing furniture and can stay as it is.

## Making changes

- Captions and the New Year screen's copy: `COPY` and `NY` in `tools/appstore.js`.
- Which app screen a frame shows: the `order` array in the same file.
- The colours each frame sits on: the `.shot--N` rules in the template.
- The phone itself: `.device` in `assets/styles.css` — one definition, used by
  the site and by these.
